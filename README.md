# 🚀 Office Pilot - Task Management System (v2.0)

## 📌 Overview 
Office Pilot is a desktop-based task management system designed to manage compliance-related services like GST, Income Tax, TDS, and more.

It includes recurring task automation, role-based dashboards, and reporting features to streamline workflow.

---

## ✨ Features
- Multi-service management (GST, IT, TDS, etc.)
- Recurring task automation (Daily, Monthly, Quarterly, Yearly)
- Role-based login (Admin & Employee)
- Employee-wise task allocation
- Status tracking system (Not Started → In Process → Task Completed)
- Due-date-based task filtering
- RDLC Reports (Done / Pending / Client-wise / Employee-wise)
- Query & Reply system
- Automatic database backup on exit

---

## 🛠️ Tech Stack
- C# (.NET WinForms)
- SQL Server
- ADO.NET
- RDLC Reports
